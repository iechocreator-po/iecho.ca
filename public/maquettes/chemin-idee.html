Le chemin d'une idée

Une seule source de vérité, bilbao. Rien n'est copié à la main d'un endroit à l'autre : chaque étape lit la précédente.

  1. 1 Onglet Anticipation Dans le produit. Un utilisateur invité vote ou propose. Écrit dans la base du produit, par compte.
  2. →
  3. 2 Console bilbao Active l'accès par compte, trie les propositions, fusionne ou décline, fait avancer le statut.
  4. →
  5. 3 features.json et releases.json Fichiers versionnés dans le dépôt de bilbao. Une carte livrée est reliée à sa note de version.
  6. →
  7. 4 iecho.ca, au build Le site lit les fichiers et fabrique la page Journal et le flux RSS. Aucun service en ligne de plus.

Dans chaque produit

Un dossier anticipation/ garde les maquettes en fichiers HTML, versionnées avec le code. L'onglet les affiche, le journal les cite.

Public ou privé, carte par carte

Chaque carte porte une visibilité. Une maquette interne reste dans bilbao ; une maquette publique apparaît dans le journal une fois la carte planifiée.

Un point de départ à trancher

Bilbao ne s'exécute qu'en local, et le journal est public : la sortie de bilbao vers iecho.ca reste un geste manuel (committer les fichiers), comme aujourd'hui pour la feuille de route.
